# Atexgrove brand assets

Use these files according to context:

- `atexgrove-logo.png` — primary transparent logo for application rendering.
- `atexgrove-logo.webp` — smaller web-delivery alternative where WebP is supported.
- `atexgrove-logo.jpg` — white-background version for documents and systems without transparency.
- `atexgrove-wordmark.*` — text-led logo and tagline.
- `atexgrove-mark.*` — construction emblem without the wordmark.
- `atexgrove-mark-32.png` and `atexgrove-mark-64.png` — small browser/icon contexts.
- `atexgrove-mark-180.png` — Apple touch icon.
- `atexgrove-mark-192.png` and `atexgrove-mark-512.png` — web-app manifest icons.
- `atexgrove-favicon.ico` — traditional browser favicon.
- `atexgrove-logo.svg`, `atexgrove-wordmark.svg`, and `atexgrove-mark.svg` — compatibility wrappers around their PNG masters.

The supplied originals are JPEG files, not vectors. The SVG is therefore a raster-backed wrapper and must not be treated as an editable master. Request the original vector artwork (`.svg`, `.ai`, `.eps`, or vector `.pdf`) from the designer before print production or large-format use.

Original files are preserved under `assets/brand/source/`. The construction-photo files are presentation mockups, not primary application assets.
