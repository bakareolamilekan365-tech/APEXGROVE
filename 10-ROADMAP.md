# APEXGROVE — Roadmap

## Phase 0 — Foundation
- Repository setup
- Environment variables
- Supabase project
- Database migrations
- Auth
- Base UI system
- RBAC

## Phase 1 — Prototype
- Profiles
- Organizations
- Land discovery
- GIS map
- Land details
- Verification workflow
- Documents
- Projects
- Professionals
- Feasibility

- Planning intelligence
- Jurisdiction rules engine
- Site analysis
- Approval workflows
- Construction management
- BOQ
- Tendering
- Procurement
- Notifications/task engine

## Phase 3 — Ecosystem expansion
- Property management
- Supplier marketplace
- Professional marketplace
- Payments
- Finance integrations
- Education
- Professional networking
- Analytics

## Phase 4 — Intelligence platform
- Advanced AI
- Document intelligence
- Advanced GIS
- Urban intelligence
- Aggregated/anonymized development datasets
- Cross-country expansion

## Rule
A later phase must not require rewriting the core identity, land, project, document, spatial or authorization models established in Phase 1 unless a genuine architectural limitation is discovered.
